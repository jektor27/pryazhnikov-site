Что такое JCode?

JCode — это десктопный ИИ-ассистент для кодирования, который работает на твоём компьютере. Никаких облаков, никаких подписок, никаких ограничений. Ты контролируешь всё: модель, ключи, файлы.

Вдохновлён Codex App от OpenAI и OpenCode, но с важным отличием: JCode — твой. Бесплатный, локальный, с поддержкой любых LLM-провайдеров.

Python FastAPI SQLite PyInstaller WebView2 Playwright Git ripgrep

Возможности

💬

Чат с ИИ

Мгновенные ответы через SSE. Поддержка markdown и кода. История всех диалогов.

📝

Patch / Diff

ИИ создаёт патчи для файлов. Визуальный diff: было/стало. Один клик — откат.

📦

Git + Ripgrep

Коммиты, статус, ветки. Быстрый поиск по коду через ripgrep.

🌐

Браузер (Playwright)

Скриншоты, клики, выполнение JS. Автоматизация веб-задач.

🔐

Песочница

Ограниченная папка для работы. Опасные команды требуют подтверждения.

📦

Сборка в exe

Один файл 76 МБ. Работает на любом ПК Windows без установки Python.

Провайдеры (кто даёт мозг)

JCode работает с любой LLM-моделью. Выбери, что подходит:

OpenCode Zen

Облако (РФ). Модель hy3-free. Работает бесплатно.

GigaChat

Облако (РФ). GigaChat-Max. Нужен ключ Сбера.

Ollama

Локально. Qwen, Llama, Mistral. Полная приватность.

DeepSeek

Облако. Мощные модели. Баланс цена/качество.

Почему JCode, а не Codex / OpenCode?

  • Бесплатно — никаких подписок ($20/мес у Codex)
  • Локально — код не покидает твой ПК
  • Любая модель — Zen, GigaChat, Ollama, DeepSeek
  • Своё — подстраивается под тебя
  • Безопасно — песочница, подтверждения, ключи в %APPDATA%
  • Автономно — работает без интернета (Ollama)
